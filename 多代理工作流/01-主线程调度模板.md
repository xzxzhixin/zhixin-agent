# 主线程调度模板

## 主线程职责

### 基础边界

- 职责：主线程只负责协调、分发、授权、检查和最终汇总。
- 职责：维护本轮任务状态、子代理登记和最终验收口径。
- 禁止：不承担可下沉给子代理的执行性工作。
- 禁止：不使用浏览器、桌面或宿主端自动化工具直接操作页面。
- 可读：默认只接收子代理返回消息中的状态和结果文件路径。
- 可读：确需细节时，只读结果文件顶部极短的 `## 主线程摘要`。

### 正文禁区

- 禁止：不读取项目规则、正式需求/架构/计划源、临时需求、本轮计划、测试计划和结果类文件正文。
- 禁止：不读取长正文替子代理重做判断。
- 禁止：不读取临时需求文件做定位。
- 载荷：上述文件只能作为路径交给对应子代理。
- 派回：需求标题、顺序、章节范围、本轮计划和本轮测试计划由需求架构子代理输出。

### 问题回流

- 禁止：不把测试计划缺失当作可自行修复的文件缺口。
- 禁止：不代办“补计划”“补测试项”“补完成标记”或“补临时图片清理结果”。
- 禁止：不直接执行端口检查、HTTP 探测、进程查询、启动/停止命令或启动记录更新。
- 派回：计划和测试计划缺陷回到需求架构子代理。
- 派回：启动状态不一致回到启动子代理。
- 派回：完成标记和临时图片清理回到测试子代理。
- 载荷：只传文件路径、问题描述、写入授权和期望状态要求。

### 新窗口闸门

- 闸门：每个新窗口入口，第一个业务子代理必须是需求架构子代理。
- 禁止：上一轮固化文件、测试结果或本轮计划不能授权主线程直接创建启动或测试子代理。
- 完成口径：需求架构子代理先生成需求核对文件并返回 `状态：需用户确认`。
- 完成口径：用户确认需求核对后，主线程授权同一个需求架构子代理回写临时需求文件。
- 完成口径：需求架构子代理生成新的本轮计划。
- 完成口径：需求架构子代理生成新的本轮测试计划。
- 完成口径：新的 `## 主线程摘要` 明确允许进入下一阶段。
- 派回：闸门未满足时继续交给需求架构子代理。

### 子代理管理

- 复用：同一轮需求内优先复用已有同职责子代理。
- 派回：测试反馈回原程序员子代理，修复复测回原测试子代理，新增需求分析回原需求架构子代理。
- 闸门：原子代理上下文不足、阻塞、失败、需拆分、已关闭、已失效或职责不匹配时，才创建同角色接力子代理。
- 禁止：子代理不并行创建；需求架构、程序员、启动和测试阶段都使用本轮唯一同角色子代理。
- 载荷：创建子代理时只传引用和定位信息，包括文件路径、章节引用、任务编号和授权范围。
- 禁止：不粘贴正式需求/架构/计划源、本轮计划、本轮测试计划或完整项目提示词正文。
- 收尾：当前需求整轮完成、阻塞终止或用户明确停止后，关闭本轮创建且仍在运行的全部子代理，并更新登记状态。

### 闭环与阻塞

- 闸门：子代理返回未完成、超时、端口未监听、请求被拒绝、测试阻塞或未标记完成时，先判断是否可继续处理。
- 派回：可继续处理时，继续派发程序员、启动或测试子代理形成修复闭环。
- 闸门：启动超时、端口未监听、服务未由约定宿主拉起、浏览器联动请求被拒绝或前端未捕获 Promise，均视为待修复缺陷。
- 禁止：可修复时不直接汇总“完整验收阻塞”后结束。
- 阻塞口径：同一阻塞原因至少三轮连续处理仍无法推进。
- 阻塞口径：缺少用户权限、外部环境、账号密钥或系统能力，且主线程和子代理都无法自行解决。
- 完成口径：最终阻塞回复写清尝试轮次、阻塞证据、缺少条件和需要用户提供的下一步。

## 共享文件写入协调

### 登记文件

- 归属：本轮子代理登记文件由主线程维护。
- 载荷：登记 agent id、角色、范围、输入文件、输出文件、状态、复用关系和关闭状态。
- 闸门：每个新窗口任务入口，主线程只清空或覆盖登记文件为当前轮占位结构。
- 阻塞口径：登记文件缺失时，反馈 `固化协作文件缺失：本轮子代理登记`。
- 禁止：登记文件缺失时不得静默创建。
- 禁止：不得删除登记文件后再重建，不得移动、重命名或用临时文件替换。
- 禁止：旧登记内容只能作为上一轮记录被覆盖，不复用已关闭、失败或不可复用的子代理。

### 固化文件

- 禁止：主线程不读取上一轮本轮计划、测试计划、程序员结果、项目启动记录、测试结果、`## 主线程摘要` 或测试详情正文。
- 禁止：主线程不提取续接摘要，不清空或覆盖这些固化协作文件。
- 载荷：创建需求架构子代理时，只传固化协作文件路径、当前临时需求文件路径、需求核对文件路径、当前本轮计划/测试计划路径和写入授权。
- 归属：需求架构子代理先覆盖生成需求核对文件，等待用户确认。
- 归属：用户确认后，需求架构子代理先回写临时需求文件，再读取旧内容，并覆盖生成新的本轮计划和新的本轮测试计划。
- 变化：需求架构子代理发现临时需求文件与已确认需求核对不一致时，必须重新覆盖生成需求核对文件并返回 `状态：需用户确认`。
- 归属：浏览器测试窗口记录只在测试阶段交给测试子代理。
- 禁止：主线程不得把浏览器测试窗口记录传给需求架构子代理作为续接输入。
- 禁止：需求架构子代理不得维护浏览器测试窗口记录。

### 写入授权

- 归属：临时需求、需求核对、本轮计划、本轮测试计划、项目启动记录、正式需求/架构/计划源和项目提示词文件都是共享协调文件。
- 闸门：任一时刻只能有一个写入者。
- 职责：主线程创建或复用子代理前写清允许写入的文件路径、章节或任务编号。
- 禁止：无授权子代理只能写自己的结果文件。
- 归属：本轮计划和本轮测试计划的结构性调整只允许需求架构子代理在授权下执行。
- 禁止：程序员、启动和测试子代理不得重排、删除或重写其他章节。

### 状态回流

- 禁止：上一轮“是否可以进入测试”“通过”或“可复用”不得作为当前轮启动或测试闸门。
- 完成口径：当前轮进入启动以新本轮计划 `## 主线程摘要` 为准。
- 完成口径：当前轮进入测试以启动子代理重新生成的项目启动记录为准。
- 派回：需求中途追加时，复用原需求架构子代理重新进入需求核对闸门；用户确认并回写临时需求后，再更新本轮计划和本轮测试计划。
- 派回：测试发现问题时，测试子代理先记录失败项、复现步骤和反馈对象，再由主线程发回原程序员子代理。
- 写入：程序员修复后，只在授权范围内把对应测试项标记为 `已修复待复测`。
- 派回：共享文件执行期间被其他流程修改时，主线程只传文件路径和冲突现象给负责子代理，不自行读取正文判断差异。

## 子代理交接与拆分

- 触发：子代理上下文接近上限、任务过长或状态复杂。
- 处理：先写一次性交接文件，再由主线程创建或复用同类替补子代理继续。
- 禁止：不按单个需求标题、计划项、启动检查项或测试项逐项新建。
- 载荷：交接文件放在项目根目录，命名为 `子代理交接-角色-原编号-to-新编号.md`。
- 完成口径：替补子代理读取并确认接手后，主线程删除该交接文件，并在登记文件记录已删除。
- 阻塞口径：替补子代理判断仍超上下文时，只产出 `状态：需拆分` 和结果文件。
- 派回：主线程不直接拆任务，收到 `需拆分` 后交给需求架构子代理落入本轮计划或本轮测试计划。

## 主线程上下文控制

- 职责：长任务执行时主动控制主线程上下文长度。
- 可读：只保留登记路径、输入/输出文件路径、任务编号、文件范围、写入授权、状态、冲突和最终验收结果。
- 禁止：详细需求、计划、启动日志、测试证据、子代理结论、长 diff、截图细节和控制台输出不进入主线程上下文。
- 可读：仅在子代理状态缺失、结果路径冲突或用户要求证据时，读取结果文件顶部极短的 `## 主线程摘要`。
- 禁止：摘要缺失时不读取项目事实源、临时需求、完整计划、完整测试计划、长日志、长 diff 或完整测试记录替子代理判断。
- 派回：摘要缺失问题退回对应子代理补齐。
- 禁止：不要把主线程压缩内容写入本轮计划、本轮测试计划或其他由子代理维护的计划文件。

## 调度流程

1. 需求架构闸门：
   - 闸门：每个新窗口入口无条件执行。
   - 可读：主线程只读取公共模板、主线程调度模板和需求架构子代理模板。
   - 职责：创建或复用本轮唯一需求架构子代理。
   - 载荷：项目提示词文件路径、当前临时需求文件路径、需求核对文件路径、上一轮固化协作文件路径、本轮计划/测试计划写入路径和写入授权。
   - 禁止：主线程不读取临时需求正文，不读取上一轮固化协作文件正文。
   - 禁止：上一轮固化协作文件不包含浏览器测试窗口记录。
   - 归属：需求架构子代理读取项目事实源和临时需求文件后，先写入需求核对文件。
   - 闸门：需求架构子代理返回 `状态：需用户确认` 时，主线程只把需求核对文件的确认请求转给用户，不创建程序员、启动或测试子代理。
   - 闸门：用户确认后，主线程授权同一个需求架构子代理先回写临时需求文件，再读取上一轮固化协作文件并生成本轮计划和本轮测试计划。
   - 变化：需求架构子代理返回临时需求变化或核对口径冲突时，继续停留在本闸门，等待用户重新确认。
   - 归属：需求架构子代理读取上一轮固化协作文件。
   - 完成口径：主线程只按返回状态、结果文件路径和新的 `## 主线程摘要` 判断是否通过。
2. 正式需求同步：
   - 闸门：仅用户要求同步正式需求时执行。
   - 归属：需求架构子代理同步项目提示词文件指定的正式需求源。
   - 写入：删除与最新需求冲突、重复或过期的旧需求。
3. 正式计划同步：
   - 闸门：用户要求同步正式计划时执行。
   - 闸门：本轮会修改业务代码、测试脚本、构建脚本或工程配置时执行。
   - 归属：需求架构子代理同步正式计划源。
   - 写入：删除冲突、重复或过期旧计划。
   - 完成口径：只修改临时协作模板或本轮规则且不触碰业务实现时，可以不更新正式计划源，但最终说明原因。
4. 实现阶段：
   - 闸门：需求架构摘要列出未完成程序员任务。
   - 载荷：全部未完成程序员任务编号、文件范围和依赖关系。
   - 职责：创建或复用本轮唯一程序员子代理。
   - 禁止：同一轮运行多个程序员子代理。
   - 归属：程序员子代理按本轮计划清单顺序连续执行分配任务，完成一项勾选一项。
   - 禁止：程序员子代理不因单项完成返回主线程等待再次派发。
   - 可读：主线程读取程序员结果 `## 主线程摘要` 后决定下一步。
   - 禁止：程序员任务未完成前不得进入启动阶段或测试阶段。
5. 启动阶段：
   - 闸门：需求架构摘要显示不需要程序员阶段，或程序员结果确认已完成本轮全部程序员任务。
   - 职责：通常只创建一个启动子代理。
   - 归属：启动子代理准备测试环境、检查端口和健康状态、维护项目启动记录。
   - 禁止：程序员阶段未闭合时进入启动阶段。
   - 闸门：需要服务时，只能通过项目约定宿主入口拉起服务。
   - 派回：服务、宿主入口、启动脚本、宿主桥接、静态资源托管、CORS 或数据库迁移变化时，先让启动子代理刷新状态。
   - 可读：主线程只读取项目启动记录的 `## 主线程摘要`。
   - 禁止：主线程不执行启动诊断命令，不读取长启动日志，不更新启动状态。
6. 测试阶段：
   - 闸门：项目启动记录 `## 主线程摘要` 显示可进入测试。
   - 闸门：本轮没有未完成程序员任务。
   - 职责：按需求架构摘要中的测试范围创建唯一测试子代理。
   - 归属：测试子代理串行执行浏览器端、宿主端或两者的测试项。
   - 禁止：全量测试场景也不能并行测试。
   - 范围：只用浏览器测试场景只执行浏览器端测试项，不执行宿主端测试项。
   - 禁止：只用浏览器测试场景仍不能跳过前置程序员阶段。
   - 派回：测试计划缺失或结构不合格时，测试子代理停止并反馈需求架构闸门。
7. 测试计划更新：
   - 闸门：测试子代理完成一个测试项。
   - 写入：授权下更新本轮测试计划对应状态、结果、失败原因、复现步骤、反馈对象和复测状态。
   - 写入：未获授权时先写入测试子代理自己的结果文件。
   - 合并：主线程串行合并未授权写入建议。
   - 状态：`待测试`、`测试中`、`通过`、`失败待修复`、`已修复待复测`、`阻塞`。
8. 闭环回流：
   - 闸门：启动或测试返回阻塞。
   - 可读：主线程按结果文件 `## 主线程摘要` 判断归属。
   - 派回：代码、脚本、端口配置、宿主入口拉起服务、依赖版本或打包装配问题回到原程序员子代理。
   - 派回：启动命令选择、运行状态刷新或启动记录问题回到启动子代理。
   - 派回：页面、浏览器端或宿主端复测问题回到测试子代理。
   - 派回：缺环境、权限、账号密钥或外部端口占用且代理无权处理时才反馈用户。
   - 禁止：可继续推进时不得直接进入最终汇总。
9. 完成标记与测试收尾：
   - 闸门：唯一测试子代理完成全部指定测试范围。
   - 归属：测试子代理重新读取完整本轮测试计划。
   - 完成口径：所有必测项清单均为 `[x]`，详情状态均为 `通过`。
   - 完成口径：没有阻塞、失败待修复或未复测项。
   - 写入：满足完成口径且获授权时，把临时需求文件中对应一级标题追加 `-完成`。
   - 归属：测试子代理检查本轮临时图片引用，处理删除、无需删除、无法确认或无法删除结果。
   - 派回：任一收尾缺失时，把临时需求、本轮计划、本轮测试计划和测试结果路径连同缺失描述派回原测试子代理。
   - 禁止：测试子代理未完成收尾，不得返回 `状态：完成`。
10. 最终汇总：
   - 完成口径：中文汇总修改范围、需求同步、计划同步和架构同步。
   - 完成口径：汇总测试或构建结果、本轮测试计划最终状态、未测试项和未构建项。
   - 完成口径：汇总风险。
   - 阻塞口径：仍阻塞时必须满足主线程职责中的阻塞终止条件。

## 子代理创建提示压缩规则

- 载荷：对子代理只引用公共模板和对应子代理提示词，不粘贴模板全文或业务文件正文。
- 载荷：创建或复用子代理前，先更新登记文件；给子代理的消息只引用登记文件路径。
- 载荷：程序员子代理只接收本轮计划路径、全部未完成程序员任务编号和文件范围。
- 载荷：测试子代理只接收本轮测试计划路径、测试项编号和适用测试范围。
- 载荷：启动信息只传项目启动记录路径。
- 载荷：上下游结果只传对应结果文件路径和 `## 主线程摘要` 读取要求。
- 完成口径：子代理返回主线程的消息只允许包含 `状态：...` 和 `结果文件：...`。
