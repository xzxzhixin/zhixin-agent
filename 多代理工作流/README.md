# 多代理工作流提示词说明

本目录保存可复用的多代理工作流提示词。它只描述公共流程、角色边界、交接方式和结果文件格式，不保存具体项目的事实源文件名、端口、启动命令、宿主规则或业务需求。

## 文件说明

- `00-公共模板.md`：所有角色共同遵守的基础规则，包括阶段顺序、共享文件写入、需求与计划规则、启动与测试边界。
- `01-主线程调度模板.md`：主线程调度规则，包括唯一同角色子代理、串行阶段闸门、共享文件写入授权和闭环回流。
- `10-需求架构子代理提示词.md`：需求定位、需求拆解、本轮计划和本轮测试计划生成规则。
- 需求核对文件：由具体项目提示词文件指定，用于计划生成前记录需求核对草案和用户确认口径。
- `20-程序员子代理提示词.md`：程序员子代理连续执行本轮计划、写入程序员结果和反馈复测规则。
- `30-启动子代理提示词.md`：启动、重启、端口检查、健康检查和项目启动记录规则。
- `40-测试子代理提示词.md`：浏览器端、宿主端测试、测试结果记录和完成标记规则。

## 使用方式

1. 在项目根目录保留一个项目提示词文件，文件名由具体项目自行决定。
2. 在项目提示词文件中声明当前项目配置，包括项目规则文件、正式需求源、正式架构源、正式计划源、临时需求文件、本轮计划、本轮测试计划、程序员结果、项目启动记录、测试结果和浏览器测试窗口记录。
3. 在项目提示词文件中声明当前项目特定规则，例如端口、启动入口、是否允许直接运行服务、测试目录和不测试的端。
4. 在入口命令中要求主线程先读取项目提示词文件，再读取本目录中的公共模板和主线程调度模板。
5. 创建子代理时，只引用对应角色提示词文件，不复制公共模板正文、项目事实源正文或长日志。

## 迁移到其他项目

迁移时复制整个 `多代理工作流/` 目录即可。新项目需要单独创建或改写自己的项目提示词文件，并至少补齐以下内容：

- 项目规则文件。
- 正式需求源。
- 正式架构源。
- 正式计划源。
- 临时需求文件。
- 本轮计划。
- 本轮测试计划。
- 需求核对文件。
- 本轮子代理登记。
- 程序员结果。
- 项目启动记录。
- 测试结果。
- 浏览器测试窗口记录。
- 项目特定启动、端口、测试和宿主约束。

不要把具体项目的规则文件名、需求文件名、架构文件名、计划文件名、端口、目录结构或宿主规则写入本目录。此类内容属于项目提示词文件。

## 协作文件处理规则

### 文件范围

- 范围：本轮子代理登记。
- 范围：需求核对文件。
- 范围：本轮计划。
- 范围：本轮测试计划。
- 范围：程序员结果。
- 范围：项目启动记录。
- 范围：测试结果。
- 范围：浏览器测试窗口记录。
- 归属：浏览器测试窗口记录由测试子代理专属维护。
- 用途：只用于复用浏览器测试专用页签。
- 禁止：浏览器测试窗口记录不参与需求架构续接整合。

### 固化文件不删除重建

- 要求：固化协作文件必须保留文件本身。
- 定义：“清空”“重置”“覆盖生成”“刷新记录”只表示保留原路径。
- 允许：替换文件内容。
- 允许：按章节更新。
- 禁止：不得删除后重建。
- 禁止：不得移动、重命名或用临时文件替换。

### 新窗口闸门

- 触发：新一轮开始。
- 允许：主线程只能重置本轮子代理登记文件。
- 禁止：主线程不能读取上一轮协作文件正文。
- 禁止：主线程不能读取上一轮 `## 主线程摘要`。
- 禁止：主线程不能清空本轮计划或本轮测试计划。
- 禁止：主线程不能清空需求核对文件。
- 禁止：主线程不能清空程序员结果、项目启动记录或测试结果。
- 禁止：主线程不能清空浏览器测试窗口记录。
- 载荷：除浏览器测试窗口记录以外的固化文件路径。
- 派回：交给需求架构子代理读取旧内容。
- 归属：需求架构子代理整合当前未完成临时需求。
- 完成口径：需求架构子代理先在授权范围内覆盖生成需求核对文件，并等待用户确认。
- 完成口径：用户确认后，需求架构子代理先回写临时需求文件，再覆盖生成新的本轮计划和新的本轮测试计划。

### 当前轮状态来源

- 归属：上一轮协作文件只作为固化记忆。
- 禁止：上一轮协作文件不能直接作为当前轮执行状态。
- 禁止：上一轮计划显示可进入测试也不能跳过需求架构闸门。
- 禁止：上一轮启动记录或测试结果显示可进入测试也不能跳过需求架构闸门。
- 归属：需求架构子代理读取当前未完成临时需求和上一轮固化文件。
- 完成口径：先生成需求核对文件并等待用户确认。
- 完成口径：用户确认并回写临时需求文件后，生成新的本轮计划和新的本轮测试计划。
- 执行：闸门完成后，再继续程序员、启动和测试流程。

### 问题回流边界

- 触发：用户指出的问题。
- 触发：流程缺陷或子代理遗漏。
- 触发：计划或测试计划未完成。
- 触发：测试未收尾、完成标记缺失或临时图片清理缺失。
- 载荷：相关文件路径、问题描述、写入授权和期望状态要求。
- 派回：对应子代理。
- 禁止：主线程不得读取协作文件正文接管修复。
- 禁止：主线程不得代写计划、测试计划、完成标记或图片清理结果。

### 测试收尾硬闸门

- 触发：测试子代理完成全部必测项通过。
- 读取：重新读取完整本轮测试计划。
- 完成口径：必测项清单为 `[x]`。
- 完成口径：详情状态为 `通过`。
- 写入：在授权下追加临时需求一级标题 `-完成`。
- 处理：检查并删除本轮临时图片引用。
- 处理：临时需求文件中引用的图片默认属于本轮临时输入资源，删除前不再询问用户。
- 写入：把清理结果写入测试结果。
- 禁止：未完成这些收尾时，测试子代理不得返回 `状态：完成`。

临时截图、一次性交接文件等明确临时资源不属于上述协作文件。它们只能按对应模板中的授权规则清理。
