# 手动验收清单

- 桌面壳：启动应用后自动拉起中心服务，退出时停止由桌面壳管理的中心服务。
- 本机 Web：访问 `http://127.0.0.1:8866` 能进入工作台。
- 远程 Web：非本机访问必须先登录，登录态使用 Cookie。
- 手机 Web：小屏下进入移动布局，消息列表独立滚动。
- IDEA 插件：工具窗口加载 `plugin.html`，右键菜单能识别文件、文件夹和选区引用。
- 中心目录迁移：复制 `center-data` 后能恢复会话、记忆、附件、供应商、插件和审计记录。
- 绿色版删除：使用默认中心目录时删除解压目录可删除程序和默认数据；使用外部中心目录时数据不随程序目录删除。
